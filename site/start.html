Install

Cogi in Claude Code

Four steps, about two minutes. Run one command at a time; after each you'll see what to expect.

  1. Get the helper, uv

    Cogi runs with uv. This installs only the helper, not Cogi yet. On a Mac:

    Terminal
    brew install uv

    On Linux or Windows, or without Homebrew, use uv's own installer, then open a new terminal so it can be found. Already have it? If uv --version works, skip this.

  2. Install Cogi

    Terminal
    claude plugin install cogito-mem --marketplace meridian21lab/cogito-mem

    Successfully installed plugin: cogito-mem@cogito-mem (scope: user)

    Needs Claude Code 2.1.292 or newer (claude --version); on older versions use the two commands under Prefer to install from inside Claude Code? below.

    Cogi now remembers in every project. Your memory is called yourname-hollow; the note that its name is "not yet set" just means that default is used. To pick another name, add --config memory_name=work-hollow.

    Stay up to date. In Claude Code, open /plugin, go to Marketplaces, pick cogito-mem and choose Enable auto-update.

  3. Check it

    Start Claude Code (claude) and type:

    In Claude Code
    /mcp

    plugin:cogito-mem:cogi ✔ 2 tools

  4. Try it

    Mention something in passing:

    Say to Claude
    Let's call the staging server "acorn".

    Wipe Claude's short-term memory:

    In Claude Code
    /clear

    And ask:

    Say to Claude
    What did we call the staging server?

    Claude answers "acorn": Cogi brought it back.

    Now peek into the hollow from a terminal:

    Terminal
    curl -s localhost:7327/v1/status

    "state": "ready", and how many messages Cogi keeps

    First time? Cogi downloads its model (310 MB) when it first wakes up, which takes about a minute. Until then the status says "starting" and Cogi finds things by their exact words only.

Good to know

Bring in your earlier sessions

Cogi starts collecting from now on. To add every Claude Code session you had before, install the cogito-mem terminal command and run it once:

Terminal
uv tool install cogito-mem
Terminal
cogito-mem capture claude-code --all

If the terminal says cogito-mem: command not found, run uv tool update-shell, open a new terminal and try again.

Prefer to install from inside Claude Code?

Type these one at a time; pasting both at once runs them as one command.

In Claude Code
/plugin marketplace add meridian21lab/cogito-mem
In Claude Code
/plugin install cogito-mem@cogito-mem

Choose Install for you (user scope), leave the name empty for yourname-hollow, then run /reload-plugins.

Other ways: Codex, Claude Desktop, Docker, Python

Every app it finds (Claude Code, Codex, Claude Desktop), with uv:

Terminal
uv tool install cogito-mem
Terminal
cogito-mem install

If the terminal says cogito-mem: command not found, run uv tool update-shell, open a new terminal and try again.

Docker, then connect Claude Code by URL:

Terminal
docker run -d --name cogito-mem -p 127.0.0.1:7327:7327 -v cogito-mem:/data ghcr.io/meridian21lab/cogito-mem
Terminal
claude mcp add --transport http cogito-mem http://127.0.0.1:7327/mcp

Python: pip install cogito-mem, then see API & MCP.

Stop Cogi from adding memories to each prompt

Add this to ~/.claude/settings.json. Claude can still search when you ask.

JSON
{ "env": { "COGITO_MEM_RECALL": "off" } }
Remove Cogi
Terminal
claude plugin uninstall cogito-mem@cogito-mem

That keeps your memories. To erase them too:

Terminal
rm -rf ~/.cogito-mem
