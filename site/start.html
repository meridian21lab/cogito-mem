Install

Cogi in Claude Code

Three steps, about two minutes. Run one command at a time.

Windows is experimental. In our Windows test, Cogi installs, saves and finds by meaning, but we haven't run it inside Claude Code there yet. If something goes wrong, tell us.

  1. Get the helper, uv

    Cogi runs with uv. If uv --version already works, skip this.

    Terminal
    brew install uv
    PowerShell
    winget install --id=astral-sh.uv -e

    Use uv's installer: one command, or your package manager.

    No Homebrew? Use uv's installer.

    Then open a new terminal, so it finds uv.

  2. Install Cogi

    Terminal
    claude plugin install cogito-mem --marketplace meridian21lab/cogito-mem

    Successfully installed plugin: cogito-mem@cogito-mem (scope: user)

    Needs Claude Code 2.1.292 or newer. Your memory is called yourname-hollow; for another name, add --config memory_name=work-hollow.

    Stay up to date: in Claude Code, open /plugin → Marketplaces → cogito-mem → Enable auto-update.

  3. Try it

    Start Claude Code (claude) and have this chat:

    Let's call the staging server “acorn”.

    /clear wipes Claude's short-term memory

    What did we call the staging server?

    “acorn”: Cogi brought it back.

    First time? Cogi downloads its model (310 MB) when it first wakes up, about a minute. Until then it finds things by their exact words only.

Good to know

Bring in your earlier sessions

Cogi collects from now on. To add every Claude Code session you had before:

Terminal
uv tool install cogito-mem
Terminal
cogito-mem capture claude-code --all

Command not found? Run uv tool update-shell, open a new terminal and try again.

Install from inside Claude Code

Type these one at a time; pasting both at once runs them as one command.

In Claude Code
/plugin marketplace add meridian21lab/cogito-mem
In Claude Code
/plugin install cogito-mem@cogito-mem

Choose Install for you (user scope), so Cogi remembers in every project, then run /reload-plugins.

Other ways: Codex, Claude Desktop, Docker, Python

Every app it finds (Claude Code, Codex, Claude Desktop):

Terminal
uv tool install cogito-mem
Terminal
cogito-mem install

Docker, then connect Claude Code by URL:

Terminal
docker run -d --name cogito-mem -p 127.0.0.1:7327:7327 -v cogito-mem:/data ghcr.io/meridian21lab/cogito-mem
Terminal
claude mcp add --transport http cogito-mem http://127.0.0.1:7327/mcp

Python: pip install cogito-mem, then see API & MCP.

Stop Cogi from adding memories to each prompt

Add this to ~/.claude/settings.json. Claude can still search when you ask.

JSON
{ "env": { "COGITO_MEM_RECALL": "off" } }
Remove Cogi
Terminal
claude plugin uninstall cogito-mem@cogito-mem

That keeps your memories. To erase them too:

Terminal
rm -rf ~/.cogito-mem
PowerShell
Remove-Item -Recurse -Force ~\.cogito-mem
