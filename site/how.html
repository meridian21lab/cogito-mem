How it works

Collect, keep, find

Every message you and Claude exchange is a nut. Cogi gathers them, keeps them in its hollow, and digs up the right ones when Claude needs them.

Collect

After each answer, Cogi picks up the new messages. Your chat never waits.

→

Keep

Word for word, with the date, in your hollow on your computer.

→

Find

It searches by exact words and by meaning, and hands back the best few.

Two ways nuts come back

On their own

~400 tokens

With each prompt, a few lines from before that match it. A new session starts with how the last one ended.

When Claude asks

2,500 tokens

Ask “do you remember…?” and Claude searches your hollow itself. This finds the most.

Each line has an id, so Claude can open the whole message and what was said around it.

The basket

Cogi fills a basket counted in tokens, the way Claude counts its room. A token is about ¾ of a word.

  • The best match goes in first, then the next, until the basket is full.
  • Long messages are kept in pieces of about 256 tokens, so one long plan can't fill it alone.

Your hollow

One memory, named after you, like ksirg-hollow. Every session from every project goes in, from Claude Code and Codex alike, so Claude can recall across them all. To peek inside:

Terminal
curl -s localhost:7327/v1/status
"ksirg-hollow": {
  "messages": 100,  ← nuts kept
  "items": 142,     ← pieces
  "vectors": 142,   ← by meaning
  "pending": 0      ← still to do
}

A different name, through COGITO_MEM_NAMESPACE, starts a new, empty hollow.

Cogi keeps what was said and what Claude did, never file contents, and it blanks out common secrets. Wrap anything in <private>…</private> to keep it out. Everything it keeps →

Under the hood
  • Meaning: EmbeddingGemma 2 (310 MB) runs on your computer in llama.cpp, so “the database choice” finds “we picked SQLite”.
  • Words: a keyword index (BM25) finds exact names and terms.
  • Together: the two rankings are merged (reciprocal rank fusion).
  • Storage: one SQLite file per hollow, only ever added to.
  • Service: a small background service on 127.0.0.1:7327 holds the model and sleeps after 12 idle hours.

That's it. You talk to Claude; Cogi minds the nuts.
