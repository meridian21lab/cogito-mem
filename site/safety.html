Safety

What you install

Cogi runs on your computer and never sends your conversations anywhere. Here is all of it, so you can check.

Your computer only

It answers only on 127.0.0.1 and refuses requests from web pages.

No cloud, no tracking

No account, no API key, no analytics. No network calls after setup.

Open source

Every line is on GitHub, MIT license.

What Cogi saves, and what it skips

Saves

  • your messages and Claude's replies, with their dates
  • commands Claude ran and files it touched
  • what each sub-agent reported
  • a few lines of command output: errors, metrics, how a run ended

Skips

  • files Claude reads
  • API keys, tokens, private keys and passwords, swapped for [redacted]
  • anything inside <private>…</private>
  • sessions from before you installed it, unless you ask

Redaction works by patterns, so an unusual secret can slip through, and a command's output can quote a line from a file. Wrap anything sensitive in <private>.

Your controls

ToSet or run
Pause savingCOGITO_MEM_CAPTURE=off
Keep no command outputCOGITO_MEM_CAPTURE_TOOL_OUTPUT=off
Keep messages onlyalso COGITO_MEM_CAPTURE_ACTIONS=off and COGITO_MEM_CAPTURE_SUBAGENTS=off
Add your past sessions, oncecogito-mem capture claude-code --all
Add them automaticallyCOGITO_MEM_BACKFILL=on: at each session start, at most hourly

Old sessions may hold secrets that redaction misses.

Check it yourself

Terminal
lsof -nP -iTCP:7327 -sTCP:LISTEN

127.0.0.1:7327 (LISTEN), never *:7327

Or switch off Wi-Fi: Cogi keeps saving and finding as before.

Remove everything

Remove the plugin
claude plugin uninstall cogito-mem@cogito-mem
Erase your memories, the model and llama.cpp
rm -rf ~/.cogito-mem
