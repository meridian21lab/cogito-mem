It finds the right conversation

LongMemEval-S is the test local memories publish: 500 questions, each with a history of about 50 chat sessions (115,000 tokens) and the sessions that hold the answer labelled. No AI model answers or grades anything, so it scores the search alone.

Each project's own published run, checked against its scoring script on 20 Oct 2026; misses are worked out from each published percentage. A few misses apart is within the noise of 500 questions, so Cogi is level with hippo-memory and deja-vu, and ahead of the rest.

Stricter than the test. Cogi searches only what was said before you ask. 44 of the questions have their answer later the same day; counting those against it, Cogi still finds the right session for 95.0%. No other memory publishes this number.

What it finds is enough to answer

On LoCoMo (10 long conversations, 1,540 questions), an AI model answers each question from what the memory hands it, and a second AI model grades the answer. This is the test Mem0's paper used for Mem0, Zep and others. From 1,000 tokens, Cogi's answers score 74.7%; rereading the whole conversation scores 76.5%.

Claude gets up to 300 tokens with each prompt by itself, and 1,000 when it searches.

Cogi shines on single facts (84.5% right at 1,000 tokens) and on dates, since every message carries its own. It is weaker on questions that need many facts at once (61.7%), where a fixed basket runs out first.

These compare designs, not hardware: hosted memories include the network and their own AI calls.

Saving a message costs one local embedding: no AI calls, no API key, $0. Services that extract facts call an AI model for every message they store, and you pay for each call.

Should you pick Cogi?

Yes, if you

  • work in Claude Code or Codex and lose context in long sessions or across days
  • want your conversations to stay on your computer
  • want no account, no API key and no bill
  • want exact words and dates, not an AI's summary

Something else, if you need

  • memory in cloud agents or claude.ai today
  • one memory shared between machines or a team
  • answers that join many facts across many sessions
  • a whole agent framework (Letta), not just memory
How we measured
  • Where: MacBook Pro, Apple M5 Max, 19–20 Oct 2026, with EmbeddingGemma 2 (Q8_0), the model that ships.
  • Finding sessions: LongMemEval-S (longmemeval_s_cleaned.json), all 500 questions, a fresh memory per question holding every message of its history. The chart lets every memory find sessions dated after the question, as LongMemEval's own scoring does; the 95.0% does not.
  • Finding messages: a LoCoMo question counts when every turn it labels as evidence is in what Cogi hands back.
  • Answers: gpt-4o-mini answers and gpt-4o-mini grades, with the Mem0 paper's prompts word for word. One run per row (about ±2.2 points). The whole conversation was run on the first 5 conversations only.
  • Speed: 1,000 searches one at a time, over 10 million tokens of synthetic text.
  • LoCoMo scores of 90% and more that some services publish use stronger answering models and more lenient graders; they are not comparable with these.

Everything is reproducible with cogito-mem eval and cogito-mem bench. Benchmarks has every number and command; the LoCoMo report has every chart and caveat.
