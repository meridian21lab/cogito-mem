Claude gets up to 300 tokens with each prompt by itself, and 1,000 when it searches.

Cogi shines on single facts (84.5% right at 1,000 tokens) and on dates, since every message carries its own. It is weaker on questions that need many facts at once (61.7%), where a fixed basket runs out first.

Free

Saving a message costs one local embedding: no AI calls, no API key, $0. Services that extract facts call an AI model for every message they store, and you pay for each call.

Should you pick Cogi?

Yes, if you

  • work in Claude Code or Codex and lose context in long sessions or across days
  • want your conversations to stay on your computer
  • want no account, no API key and no bill
  • want exact words and dates, not an AI's summary

Something else, if you need

  • memory in cloud agents or claude.ai today
  • one memory shared between machines or a team
  • answers that join many facts across many sessions
  • a whole agent framework (Letta), not just memory
How we measured
  • Where: MacBook Pro, Apple M5 Max, 19 Oct 2026, with EmbeddingGemma 2 (Q8_0), the model that ships.
  • Answers: gpt-4o-mini answers and gpt-4o-mini grades, with the Mem0 paper's prompts word for word. One run per row (about ±2.2 points). The whole conversation was run on the first 5 conversations only.
  • Finding messages: a question counts when every turn LoCoMo labels as evidence is in what Cogi hands back.
  • Speed: 1,000 searches one at a time, over 10 million tokens of synthetic text.
  • Newer scores of 90% and more that some services publish use stronger answering models and more lenient graders; they are not comparable with these.

Everything is reproducible with cogito-mem eval and cogito-mem bench; the full report has every number, chart and caveat.
