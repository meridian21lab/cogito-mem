Results

It remembers. We measured.

We put Cogi through the benchmarks memory tools are judged by, on a laptop, with the exact model it ships with. In 1.2 million tokens of chat history it finds the right past conversation 93 times in 100, ahead of four other local memories, and from a ninth of the reading it gives 95% of the answers you'd get by rereading the whole chat. No account, no API key, no bill.

Finds the right conversation in 1.2 million tokens

Each of LongMemEval's 500 questions hides its answer in past chat sessions. In its long test there are about 480 of them per question, some 1.2 million tokens: more than Claude can read at once. Cogi finds the right one among its first five for 465 of the 500, with no AI model in the loop.

Hands Claude the messages, not whole old sessions

Claude doesn't read a ranking; it reads the text a memory hands back. Given the same 2,500 tokens, Cogi's reply holds every message the answer needs for 71% of questions. Some other plugins hand back whole old sessions, which fill the space before the part that matters.

Most of the answers, a ninth of the reading

On LoCoMo, the test Mem0 and Zep were measured with, an AI model answers each question from what the memory hands it. With today's models, 1,000 tokens of Cogi's memory give 95% of the score of rereading the entire conversation, while the model reads about 9 times fewer tokens. Rereading everything still answers best, 3 to 5 points higher, but it stops being possible once your history outgrows the context window.

Should you pick Cogi?

Yes, if you

  • work in Claude Code or Codex and lose context in long sessions or across days
  • want your conversations to stay on your computer
  • want no account, no API key and no bill
  • want exact words and dates, not an AI's summary

Something else, if you need

  • memory in cloud agents or claude.ai today
  • one memory shared between machines or a team
  • answers that join many facts across many sessions
  • a whole agent framework (Letta), not just memory
