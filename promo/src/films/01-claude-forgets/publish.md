## YouTube Short

**Title:** Claude forgets. Cogi doesn't. #Shorts

**Description:**

Your AI assistant has the memory of a goldfish. Cogi keeps every message you and Claude exchange, word for word, with its date, in one folder on your own computer. When something drops out of the conversation, Claude searches Cogi and gets your exact words back.

Free and open source. No account, no API key, no AI calls to save a message.

Install (needs Claude Code and uv):
claude plugin install cogito-mem --marketplace meridian21lab/cogito-mem

Try it: tell Claude "the staging server is called acorn", start a new chat, then ask what it's called.

Cogi: https://meridian21lab.github.io/cogito-mem/
Source (MIT): https://github.com/meridian21lab/cogito-mem
How I tested it: https://ai.ksopyla.com/posts/cogi-memory-evals/
