## YouTube Short

**Title:** Your memory stays home. #Shorts

**Description:**

Cogi keeps every message you and Claude exchange, word for word, with its date, in one folder on your own computer (~/.cogito-mem). No account, no API key, no AI calls to save a message, and nothing is sent anywhere. Text you wrap in <private>…</private> is not saved at all.

When something drops out of the conversation, Claude searches Cogi and gets your exact words back.

Install (needs Claude Code and uv):
claude plugin install cogito-mem --marketplace meridian21lab/cogito-mem

Every file, download and connection it makes: https://meridian21lab.github.io/cogito-mem/safety.html
